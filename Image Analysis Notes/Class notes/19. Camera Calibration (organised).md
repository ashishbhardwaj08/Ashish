# 1. Image Formation Model

Real world point:

$X = [X \ Y \ Z \ 1]^T$

Image point:

$x = [x \ y \ 1]^T$

Projection relation:

$x \sim PX$

Expanded form:

$$
\begin{bmatrix}
x\\
y\\
q
\end{bmatrix}
=
P
\begin{bmatrix}
X\\
Y\\
Z\\
1
\end{bmatrix}
$$

Symbol “($\sim$)” represents equality up to scale.

---

# 2. Projection Matrix

Projection matrix:

$P = K[R|T]$

Complete equation:

$x \sim K[R|T]X$

Another notation:

$x \sim MX$

where

$M = K[R|T]$

Projection matrix size: 3 X 4

Total parameters: 12


---

# 3. Intrinsic Parameters

Intrinsic parameters represent internal camera properties.

Intrinsic matrix:


$$K =
\begin{bmatrix}
f_x & s & c_x\\
0 & f_y & c_y\\
0 & 0 & 1
\end{bmatrix}$$

Parameters:

- ($f_x, f_y$) → focal lengths
- ($c_x, c_y$) → principal point
- (s) → skew

Applications:

- Camera calibration
- Distortion correction
- Metric reconstruction

---

# 4. Extrinsic Parameters

Extrinsic parameters represent camera pose.

Components:

- Rotation matrix (R)
- Translation vector (T)

Combined form: [R|T]  

Purpose:

- Mapping world coordinates into camera coordinates

---

# 5. Combining All Matrices

Instead of separate transformations:

- World transformation
- Camera transformation
- Projection transformation

Combined representation:
  
M = K[R|T] 

Advantages:

- Single matrix multiplication
- Simplified computation
- Faster estimation

---

# 6. Inverse Projection

Projection:  
3D → 2D

Inverse projection:  
2D → possible 3D ray

Single pixel corresponds to infinitely many 3D points along viewing direction.

Depth information required for unique reconstruction.

Applications:

- Stereo vision
- Depth estimation
- 3D reconstruction

---

# 7. Perspective and Weak Perspective

Real camera image:

- Strong perspective projection

Observed effects:

- Distant objects appear smaller
- Parallel lines converge

Weak perspective approximation:

- Small depth variation assumption
- Simplified equations

Applications:

- Face tracking
- Motion estimation
- Structure from motion

---

# 8. Orthographic Projection

Projection without perspective distortion.

Equation:

x = X 
y = Y

Properties:

- Parallel lines remain parallel
- Object size independent of depth

Applications:

- Engineering drawing
- Simplified reconstruction

---

# 9. Scaled Orthographic Projection

Orthographic projection with scaling factor.

Equation:

x = sX
y = sY

where:

- (s) = scale parameter

Applications:

- Approximate perspective modeling

---

# 10. Affine Orthographic Model

Affine transformation added to orthographic model.

Properties:

- Preserves parallelism
- Allows shear and scaling

Applications:

- Image registration
- Motion tracking

---

# 11. Perspective Cues

Depth information obtained from perspective properties.

Important cues:

- Relative size
- Vanishing points
- Texture gradient
- Occlusion

Applications:

- Scene understanding
- Depth perception

---

# 12. Projection Matrix Estimation

Goal:  
Estimate matrix (M).

Equation:

$x \sim MX$

Unknowns:  
12 parameters

Each point correspondence provides:  
2 equations

Minimum correspondences:  
6 non-degenerate points

Points from different planes improve stability.

---

# 13. Least Squares Method

Real data contains noise.

Exact solution generally impossible.

Least squares minimizes total error.

Error function:

$E = \sum_i (y_i - \hat{y}_i)^2$

Applications:

- Projection matrix estimation
- Line fitting
- Calibration

---

# 14. Normal Equation

Least squares solution:

$\theta = (X^TX)^{-1}X^Ty$


Known as:  
Normal equation

Applications:

- Linear regression
- Parameter estimation

---

# 15. Linear Regression

Linear relation:

y = mx + c


Goal:  
Estimate:

- slope (m)
- intercept (c)

Optimization target:  
Minimum squared error.

---

# 16. Regression as Optimization

Regression problem transformed into optimization problem.

General form:

$\min E(\theta)$

Subject to constraints.

Examples:

- Geometric constraints
- Rank constraints
- Orthogonality constraints

---

# 17. Error Minimization at Convergence

Iterative optimization process:

- Initial estimate
- Repeated updates
- Convergence toward minimum error

At convergence:

$\frac{\partial E}{\partial \theta} = 0$


Applications:

- Bundle adjustment
- Neural networks
- Nonlinear fitting

---

# 18. Nonlinear Problems in Computer Vision

Most computer vision equations are nonlinear.

Sources:

- Perspective projection
- Rotation matrices
- Exponential relations

Examples:

- Camera calibration
- Optical flow
- Pose estimation

Linearization methods often required.

---

# 19. Log Transformation for Nonlinear Equations

Example nonlinear model:

$y = ae^{bx}$

Taking logarithm:

$\log y = \log a + bx$


Transformation converts nonlinear relation into linear form.

Advantages:

- Simpler optimization
- Easier parameter estimation

---

# 20. General Order Equation for Curve

Polynomial curve:


$y = a_nx^n + a_{n-1}x^{n-1} + \dots + a_1x + a_0$


Applications:

- Curve fitting
- Boundary modeling
- Shape approximation

---

# 21. First Order Histogram

First order histogram uses:  
Single pixel intensity statistics.

Information:

- Intensity distribution
- Frequency of gray levels

No neighborhood relation included.

Applications:

- Thresholding
- Contrast analysis

---

# 22. Second Order Histogram

Second order statistics include neighboring pixel relationships.

Most common representation:  
Co-occurrence matrix.

---

# 23. Co-occurrence Matrix

Measures:  
How frequently two intensity values occur together.

Matrix element:

C(i,j)

represents frequency of:

- intensity (i)
- occurring near intensity (j)

Texture features derived:

- Contrast
- Energy
- Homogeneity
- Correlation

Applications:

- Texture classification
- Medical imaging
- Remote sensing

---

# 24. Expected Value

Expected value represents average outcome.

Discrete form:


$E[X] = \sum xP(x)$  

Practical approximation:  
Bin average from histogram.

Applications:

- Statistical estimation
- Mean intensity computation

---

# 25. Maximum Likelihood Estimation (MLE)

Goal:  
Find parameter maximizing probability of observed data.

Likelihood:


$L(\theta) = P(Data|\theta$)


MLE estimate:


$\hat{\theta} = \arg\max_\theta L(\theta)$


Applications:

- Parameter estimation
- Classification
- Gaussian fitting

---

# 26. Log Likelihood

Logarithm applied to likelihood:


$\log L(\theta)$


Advantages:

- Converts multiplication into addition
- Numerical stability
- Easier differentiation

Applications:

- Deep learning
- Statistical modeling

---

# 27. Expectation Maximization (EM)

Iterative probabilistic optimization algorithm.

Two steps:

## E-step

Expectation computation using current parameters.

## M-step

Parameter update maximizing likelihood.

Applications:

- Gaussian mixture model
- Missing data estimation
- Clustering

---

# 28. LMS (Least Mean Squares)

Adaptive optimization algorithm.

Weight update:

$w_{new} = w_{old} + \eta e x$


where:

- (\eta) = learning rate
- (e) = error

Applications:

- Adaptive filtering
- Neural learning
- Signal processing

---

Methods:

# 30. Optical Flow

Optical flow estimates apparent motion between frames.

Assumption:  
Brightness constancy.

Equation:


$I_xu + I_yv + I_t = 0$


where:

- (I_x, I_y) → spatial gradients
- (I_t) → temporal gradient
- (u,v) → motion components

Applications:

- Motion tracking
- Video analysis
- Autonomous driving
